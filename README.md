# StudyFlow — Study Planner and Productivity Tracker

This is a beginner-friendly web app built with Python, Flask, SQLite, HTML, and CSS.

## Files
- `app.py` - the Python server code
- `study.db` - the SQLite database file created automatically
- `templates/index.html` - the web page layout
- `static/styles.css` - the page styling

## How to run
1. Open PowerShell in the `study-planner` folder.
2. Install Flask with:
   ```powershell
   pip install -r requirements.txt
   ```
3. Start the app:
   ```powershell
   python app.py
   ```
4. Open your browser and go to `http://127.0.0.1:5000/`.

## What you can do
- Add a study task
- Mark tasks complete
- Delete tasks
- See progress as a percentage
